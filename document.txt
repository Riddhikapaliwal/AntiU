Think of `pool` as a bank of database connections, and `client` as one specific connection borrowed from that bank.

- `pool.query()` — the pool handles the connection for each query.
- `client.query()` — you use the same borrowed connection for every query.

Why does that matter?

```
const client = await pool.connect();

await client.query('BEGIN');
await client.query('INSERT ...');
await client.query('INSERT ...');
await client.query('COMMIT');

client.release();
```

All queries run on the same connection, so PostgreSQL knows both inserts belong to the same transaction. If one fails, you can `ROLLBACK` both.

Remember: `pool.connect()` borrows the connection; `client.release()` returns it to the pool.
